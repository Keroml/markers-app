# markers-app

Мобильное приложение на React Native (Expo) с картой, маркерами, локальной базой данных SQLite и геолокацией.

## Возможности

- Интерактивная карта (`react-native-maps`) на весь экран
- Определение текущего местоположения через GPS (`expo-location`) с центрированием камеры на пользователе
- Добавление маркеров долгим нажатием на карту
- **Цвет маркера зависит от наличия фото:** синий — фото нет, красный — есть
- **Переименование маркеров** (необязательное название)
- Экран деталей маркера с координатами и названием
- Добавление изображений из галереи (`expo-image-picker`)
- Удаление изображений и маркеров (с каскадным удалением связанных данных)
- Локальное хранение в SQLite (`expo-sqlite`)
- Копирование изображений в постоянную папку приложения (`expo-file-system`)
- Обработка ошибок: инициализация БД, выбор изображений, геолокация, навигация, «маркер не найден»

## Установка и запуск

### Требования

- Node.js (LTS)
- Expo Go на мобильном устройстве (iOS/Android)
- npm или yarn

### Шаги

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd markers-app

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npx expo start

# 4. Отсканировать QR-код в Expo Go
